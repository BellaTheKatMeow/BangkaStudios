What Engine Do We Used?

 

 

About The Game engines!

 

We mostly used different variety of game engines which are mostly specific to genre or features that we are trying to do!

Games Engines are divided in :

Specialized Game Engines : This are engines that are specific to the genre that we are making.

We mostly choose this path if the specific game lines up with the specific genre and the mechanics assumption it does out of the get go.

General Game Engines : The 'we can do it all engine' , we mostly used this engine if the genre is mixed and the mechanics are a more complicated one
